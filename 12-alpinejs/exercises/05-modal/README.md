# Exercise 05 - Modal Component with Alpine.js

## Objective
Create a reusable modal component using Alpine.js with animations, nested modals, and proper accessibility.

## Requirements

### Core Features
- Open and close modal
- Overlay/backdrop
- Close button
- Click outside to close
- Prevent background scroll

### Advanced Features
- Multiple independent modals
- Nested/stacked modals
- Smooth animations
- Keyboard handling (Escape to close)
- Focus management
- Accessibility (ARIA attributes)
- Confirm/Cancel actions

## Starter Code
Open `starter.html` to begin the exercise.

## Alpine.js Directives
- x-show/x-if for modal visibility
- x-on for event handling
- @click.outside for backdrop detection
- @keydown for keyboard events
- Animations and transitions

## Learning Points
- Modal patterns and best practices
- Focus trapping and management
- Accessibility considerations
- Event handling and delegation
- Animation techniques
