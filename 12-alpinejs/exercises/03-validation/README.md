# Exercise 03 - Form Validation with Alpine.js

## Objective
Implement comprehensive form validation using Alpine.js with real-time feedback and error messages.

## Requirements

### Core Features
- Validate required fields
- Real-time validation feedback
- Show/hide error messages
- Disable submit button if invalid
- Validate email, password, matching passwords

### Advanced Features
- Password strength meter
- Custom validation rules
- Dynamic field validation
- Error summary
- Success messaging

## Starter Code
Open `starter.html` to begin the exercise.

## Alpine.js Concepts
- x-model for form binding
- x-on for event handling
- Computed properties for validation
- Conditional rendering with x-show
- Class binding for styling
