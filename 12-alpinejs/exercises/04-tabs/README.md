# Exercise 04 - Tabs Component with Alpine.js

## Objective
Build a reusable tabs component using Alpine.js with tab switching, content rendering, and keyboard navigation.

## Requirements

### Core Features
- Multiple tabs with content
- Click to switch tabs
- Active tab styling
- Hide/show content based on active tab
- Tab labels and icons

### Advanced Features
- Keyboard navigation (arrow keys)
- Lazy loading content
- Animations/transitions
- Dynamic tab addition/removal
- Remember selected tab
- Accessibility (ARIA attributes)

## Starter Code
Open `starter.html` to begin the exercise.

## Alpine.js Concepts
- x-data for component state
- x-on for click handling
- x-show/x-if for conditional rendering
- Computed properties
- @keydown for keyboard events
- Class binding for active states

## Learning Points
- Component composition
- State management
- Tab navigation patterns
- Keyboard accessibility
- Content switching
