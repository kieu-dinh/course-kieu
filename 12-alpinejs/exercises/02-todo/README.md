# Exercise 02 - Todo List with Alpine.js

## Objective
Build a fully functional todo list using Alpine.js, incorporating data binding, event handling, and list manipulation.

## Requirements

### Core Features
- Add new todos
- Display todo list
- Mark todos as complete
- Delete todos
- Edit todos
- Clear completed todos

### Advanced Features
- Filter todos (All, Active, Completed)
- Count active and completed items
- Persist todos with localStorage
- Keyboard shortcuts (Enter to add)
- Search/filter functionality
- Drag and drop reordering

## Starter Code
Open `starter.html` to begin the exercise.

## Alpine.js Concepts
- x-for for rendering lists
- x-model for two-way binding
- x-on for event handling
- x-show/x-if for conditionals
- @keydown for keyboard events
- Computed properties with getters

## Learning Points
- List rendering and management
- Event handling with keyboards
- Two-way data binding
- Array manipulation methods
- Conditional rendering
- Local storage integration
