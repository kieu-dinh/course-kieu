# Exercise 01 - Counter with Alpine.js

## Objective
Build a simple counter component using Alpine.js, learning basic reactivity and event handling.

## Requirements

### Core Features
- Display counter value
- Increment button
- Decrement button
- Reset button
- Display step value

### Advanced Features
- Adjustable step size
- Min/max limits
- History of changes
- Persistence with localStorage
- Multiple independent counters

## Starter Code
Open `starter.html` to begin the exercise.

## Learning Points
- Alpine.js basic syntax (x-data, x-text, x-on)
- Data binding and reactivity
- Event handling with @click
- Conditional rendering with x-show/x-if
- List rendering with x-for
- Computed properties and methods

## Key Alpine.js Directives
- `x-data`: Initialize component state
- `x-text`: Bind text content
- `x-on:click` or `@click`: Handle click events
- `x-bind:value` or `:value`: Bind element properties
- `x-show`: Conditionally display elements
- `x-if`: Conditionally render elements
- `x-for`: Loop through arrays
