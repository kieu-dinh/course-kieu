# Module 12 - Alpine.js

**Duration**: 1-2 weeks
**Prerequisites**: Module 11 - JavaScript Basics

---

## Learning Objectives

- Understand reactive JavaScript frameworks
- Use Alpine.js directives (x-data, x-show, x-on, etc.)
- Build interactive components without heavy frameworks
- Prepare for Livewire concepts later

---

## Why Alpine.js?

Alpine is like "jQuery for the modern web" - lightweight, simple, powerful.

**Perfect for adding interactivity without React/Vue complexity!**

Later, you'll see how Livewire uses Alpine under the hood!

---

## Topics Covered

1. Alpine.js installation and setup
2. x-data (reactive data)
3. x-show, x-if (conditional rendering)
4. x-for (loops)
5. x-on (event handling)
6. x-model (two-way binding)
7. x-bind (dynamic attributes)
8. Alpine components
9. Alpine plugins
