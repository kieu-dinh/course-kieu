# Exercise 02 - POST Data to API

## Objective
Learn to send data to a server using POST requests and handle responses.

## Requirements

### Core Features
- Create form to collect data
- Send POST request with form data
- Handle response from server
- Show success/error messages
- Display returned data

### Advanced Features
- Form validation before submit
- Request headers and content types
- File uploads
- Multiple POST endpoints
- Request cancellation
- Retry failed requests

## Starter Code
Open `starter.html` to begin the exercise.

## Public Testing APIs
- JSONPlaceholder: Creates fake resources
  - POST /posts - Create post
  - POST /comments - Create comment
  - POST /users - Create user
- ReqRes: User data testing
  - POST /api/users - Create user

## Learning Points
- POST request methods
- FormData API
- Request headers
- Response handling
- Error states
- User feedback
