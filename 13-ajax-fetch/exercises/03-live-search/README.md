# Exercise 03 - Live Search with API Calls

## Objective
Implement a live search feature that makes API calls as users type to filter and display results in real-time.

## Requirements

### Core Features
- Input field for search query
- Real-time API calls on input
- Display search results dynamically
- Debouncing to reduce API calls
- Clear results button
- Loading indicator

### Advanced Features
- Highlight search terms in results
- Search history
- Suggestions/autocomplete
- Pagination of results
- Filter results
- Cache results

## Starter Code
Open `starter.html` to begin the exercise.

## APIs to Use
- JSONPlaceholder: Search posts and users
- Wikipedia API: Search articles
- Open Library API: Search books

## Learning Points
- Debouncing function calls
- Request cancellation
- Handling rapid requests
- Result filtering
- Text highlighting
- User experience optimization
