# Exercise 01 - Fetch and Display Data

## Objective
Learn to fetch data from a public API and display it dynamically on a webpage.

## Requirements

### Core Features
- Fetch data from public API (JSONPlaceholder or similar)
- Parse JSON response
- Display data in HTML list or cards
- Show loading state
- Handle errors gracefully

### Advanced Features
- Filter and search results
- Sort data
- Pagination
- Caching fetched data
- Refresh button
- Empty state handling

## Starter Code
Open `starter.html` to begin the exercise.

## Public APIs
- JSONPlaceholder: https://jsonplaceholder.typicode.com/
  - Posts: /posts (100 posts)
  - Users: /users (10 users)
  - Comments: /comments (500 comments)
- Random User API: https://randomuser.me/api/?results=10

## Learning Points
- Async/await and Promises
- Fetch API basics
- JSON parsing
- DOM manipulation with dynamic data
- Loading and error states
- Data visualization
