# Exercise 04 - Infinite Scroll Load More

## Objective
Implement infinite scroll functionality that loads more data as users scroll to the bottom of the page.

## Requirements

### Core Features
- Load initial set of items
- Detect when user scrolls near bottom
- Load more items automatically
- Show loading indicator
- Prevent duplicate requests
- Loading complete indicator

### Advanced Features
- "Load More" button alternative
- Scroll position restoration
- Filter and pagination with scroll
- Custom scroll threshold
- Performance optimization

## Starter Code
Open `starter.html` to begin the exercise.

## Learning Points
- Scroll event handling
- Intersection Observer API
- Request throttling
- Loading state management
- Performance considerations
- DOM manipulation with lists
