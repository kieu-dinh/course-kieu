# Exercise 05 - Single-Page App Basics

## Objective
Build a basic single-page application (SPA) with client-side routing and dynamic content loading.

## Requirements

### Core Features
- Multiple pages/views
- Client-side routing (hash/history API)
- Load content without page refresh
- Navigation menu
- Active page indicator
- Browser back/forward support

### Advanced Features
- Lazy loading content
- State management
- Animations between pages
- Deep linking support
- Page metadata (title, description)
- URL parameters

## Starter Code
Open `starter.html` to begin the exercise.

## SPA Concepts
- Hash-based routing (#/)
- History API for URL changes
- Dynamic content loading
- View management
- Navigation patterns

## Learning Points
- SPA architecture patterns
- Client-side routing strategies
- State management basics
- URL handling
- User experience optimization
