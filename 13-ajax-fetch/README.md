# Module 13 - AJAX & Fetch API

**Duration**: 1-2 weeks
**Prerequisites**: Module 12 - Alpine.js

---

## Learning Objectives

- Understand AJAX (Asynchronous JavaScript and XML)
- Use Fetch API to communicate with backend
- Handle loading states and errors
- Build SPA-like experiences
- Combine Alpine.js with API calls

---

## Topics Covered

1. What is AJAX?
2. Fetch API basics
3. GET, POST, PUT, DELETE with Fetch
4. Handling JSON responses
5. Error handling
6. Loading states
7. Combining Alpine + Fetch
8. CORS understanding
