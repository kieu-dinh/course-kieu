# Environment Verification Checklist

Complete this checklist to verify your environment is ready.

## VS Code
- [ ] VS Code opens correctly
- [ ] I can create a new file (File > New File)
- [ ] I installed PHP Intelephense extension
- [ ] I installed Tailwind CSS IntelliSense extension
- [ ] I installed Alpine.js IntelliSense extension
- [ ] I installed Laravel Blade Snippets extension
- [ ] I installed GitLens extension

## Browser
- [ ] I can open Developer Tools (F12 or right-click > Inspect)
- [ ] I can see the Elements tab
- [ ] I can see the Console tab
- [ ] I can see the Network tab

## Terminal
- [ ] I can open the terminal
- [ ] `php -v` shows a version number: _________
- [ ] `node -v` shows a version number: _________
- [ ] `npm -v` shows a version number: _________
- [ ] `composer -v` shows Composer information
- [ ] I understand `cd`, `ls`, `pwd`, `mkdir` commands

## GitHub
- [ ] I have a GitHub account
- [ ] My GitHub username is: _________
- [ ] I can log in to github.com

## Learning Folder
- [ ] I created my learning folder
- [ ] Path to my folder: _________
- [ ] I can open it in VS Code with `code .`
