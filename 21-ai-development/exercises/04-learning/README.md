# Exercise 21.4 - Learning with AI

## Objective

Use AI as a tutor to accelerate your learning of new concepts, frameworks, and techniques.

---

## Task

Use AI to create a personalized learning plan and master a new topic.

---

## Effective Learning Prompts

### Prompt Type 1: Concept Explanation

```
Explain [CONCEPT] to me.

My experience:
- Programming experience: [YEARS]
- Tech stack: [STACK]
- What I already know: [CONCEPTS]

I'm learning this because: [REASON]

Please:
1. Give me a simple explanation
2. Show a practical example in [LANGUAGE]
3. Compare it to something I know
4. Point out common mistakes
5. Suggest where to use it

Format: Keep it concise but complete
```

### Prompt Type 2: Learning Path

```
I want to learn [TOPIC].

My background:
- Current skills: [SKILLS]
- Experience level: [LEVEL]
- Time available: [TIME]
- Learning style: [STYLE]

Goals:
1. [GOAL 1]
2. [GOAL 2]
3. [GOAL 3]

Create a learning path:
1. Prerequisites to master first
2. Logical learning order
3. Practical projects for each step
4. Estimated time per step
5. How to know you understand

Make it progressive and practical.
```

### Prompt Type 3: Deep Dive

```
I want to deeply understand [TOPIC].

Show me:
1. How it works under the hood
2. Why it was created
3. Trade-offs and limitations
4. When to use vs. alternatives
5. Real-world applications

Use:
- Analogies I can relate to
- Visual descriptions
- Code examples
- Real scenarios

Target audience: Someone who learns by understanding, not memorizing.
```

### Prompt Type 4: Troubleshooting Learning

```
I'm struggling with [CONCEPT].

What I've tried:
[WHAT YOU'VE TRIED]

I understand:
- [WHAT YOU GET]

I don't understand:
- [WHAT YOU DON'T GET]

Help me by:
1. Identifying what's confusing
2. Explaining differently
3. Providing different examples
4. Breaking it into smaller pieces
5. Showing common mistakes
```

## Learning Techniques

### Technique 1: Teach Back

Learn by explaining:

```
I just learned [CONCEPT].

Explain [CONCEPT] to me as if I were a junior developer.

Include:
1. What it is
2. Why it matters
3. How it works
4. Practical example
5. Common mistakes

If I get something wrong, correct me and explain why.
```

### Technique 2: Apply Knowledge

Learn by doing:

```
I learned about [CONCEPT] in Laravel.

Give me a realistic exercise where I:
1. Build something practical
2. Use [CONCEPT] correctly
3. Make a common mistake
4. Fix the mistake

Include:
- Starting code
- Step-by-step guide
- Tips for success
- How to verify it works
- How to extend it further
```

### Technique 3: Compare and Contrast

Learn by comparison:

```
Compare [CONCEPT A] and [CONCEPT B].

Explain:
1. What each does
2. Key differences
3. When to use each
4. Code examples for both
5. Trade-offs
6. How they work together

Use a table to show the comparison clearly.
```

### Technique 4: Deep Questions

Learn by asking:

```
I'm confused about [CONCEPT].

Answer these questions:
1. [QUESTION 1]
2. [QUESTION 2]
3. [QUESTION 3]

For each answer, include:
- Direct answer
- Why it's true
- Code example
- Common misunderstanding
- How it connects to [RELATED CONCEPT]
```

## Concrete Examples

### Learning Example 1: Laravel Eloquent Relationships

```
I want to master Laravel Eloquent relationships.

What I know:
- Basic database concepts
- How to query with Eloquent
- What relationships do in theory

What I want to understand:
1. Types of relationships (hasMany, belongsTo, etc.)
2. How they work under the hood
3. How to use them efficiently (eager loading)
4. Advanced relationships (polymorphic, etc.)
5. Common N+1 problems and fixes

Teach me by:
1. Explaining each type with real-world example
2. Showing the database query it generates
3. Showing common mistakes
4. Providing a practical exercise

Time available: 2 hours
```

### Learning Example 2: Queue Jobs

```
I want to understand Laravel Queue jobs.

I know:
- Controllers and services
- Database operations
- Basic Laravel structure

I don't know:
- Why queues are needed
- How they work
- How to implement them
- Testing queued jobs

Teach me:
1. What problem queues solve (with examples)
2. How Laravel queues work (architecture)
3. Step-by-step: create, dispatch, process
4. Testing queued jobs
5. Debugging failed jobs

Show me:
- Real-world scenario
- Before (without queues) and after code
- Performance comparison
- Production setup

Give me an exercise to practice.
```

### Learning Example 3: Database Optimization

```
I want to learn database optimization.

Current level:
- Can write SQL queries
- Understand basic database concepts
- Don't know about optimization

Teach me:
1. Identifying slow queries
2. Creating effective indexes
3. Query optimization techniques
4. N+1 problems and solutions
5. Caching strategies
6. When optimization matters

For each topic:
- Explain why it matters
- Real example showing the problem
- Solution with code
- Measurement/monitoring
- When to apply

Give me a project to practice on.
```

## Accelerated Learning

### Spaced Repetition

```
I need to master [CONCEPT].

Create a spaced repetition study schedule:
1. What to study today (Day 1)
2. What to review on Day 2
3. What to practice on Day 3
4. When to do deeper dive (Day 5)
5. When to teach back (Day 7)
6. When to apply (Day 10)

Include:
- Specific questions to answer
- Exercises to do
- Projects to build
- Topics to research

Target: Real understanding, not just memorization
```

### Active Recall

```
Test my understanding of [CONCEPT].

Ask me progressively harder questions:
1. Basic definition
2. How it works
3. When to use it
4. Trade-offs
5. Advanced application
6. Teaching someone else

If I answer wrong:
1. Tell me the right answer
2. Explain why
3. Ask again later
```
