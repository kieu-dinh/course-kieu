# Module 16 - Laravel Authentication & Security

**Duration**: 2 weeks
**Prerequisites**: Module 15 - Eloquent ORM

---

## Learning Objectives

- Use Laravel Breeze for authentication
- Understand Laravel's auth system
- Implement authorization (Gates, Policies)
- Role-based access control
- Compare to your pure PHP auth (Module 07!)

---

## "I Built This!" Moments

**Remember Module 07?** You built an entire auth system from scratch!

**Now Laravel does it in ONE command:**
```bash
composer require laravel/breeze --dev
php artisan breeze:install
```

**But YOU understand what it's doing under the hood!**

---

## Topics Covered

1. Laravel Breeze installation
2. Authentication scaffolding
3. Login, register, password reset
4. Middleware (auth, guest)
5. Gates and Policies
6. Authorization checks
7. Role-based permissions
8. API authentication (Sanctum)
