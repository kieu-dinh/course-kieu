## Setup

### Running PHP

With Laravel Herd, PHP is ready. Create a file and run it:

```bash
# Create file
touch test.php

# Add code
echo '<?php echo "Hello PHP!"; ?>' > test.php

# Run it
php test.php
```

### PHP Files

PHP code goes between `<?php` and `?>`:

```php
<?php
// Your code here
echo "Hello World!";
?>
```

If file is pure PHP, skip the closing tag:

```php
<?php
echo "Hello World!";
```

## What is an Algorithm?

An algorithm is a sequence of steps to solve a problem.

**Example: Making coffee**
1. Fill kettle with water
2. Boil water
3. Put coffee in cup
4. Pour hot water
5. Stir
6. Done!

Programming is writing algorithms for computers.
