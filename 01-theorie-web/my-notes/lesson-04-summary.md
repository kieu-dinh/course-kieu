# Lesson 04 Summary - Frontend vs Backend

## The Two Sides of Web Development

| | Frontend | Backend |
|---|----------|---------|
| **Where?** | In your browser | On the server |
| **Who sees it?** | The user | Nobody (hidden) |
| **Languages** | HTML, CSS, JavaScript | PHP, Python, etc. |
| **Purpose** | Show things, look pretty | Process data, store info |

---

## Frontend = What the User Sees

Runs in the browser. The 3 languages:

| Language | Role | Analogy |
|----------|------|---------|
| **HTML** | Structure | The skeleton/bones |
| **CSS** | Style | The clothes/appearance |
| **JavaScript** | Interactivity | The muscles/movement |

---

## Backend = What the Server Does

Runs on the server. Handles:
- Check if password is correct
- Save data to database
- Send emails
- Process payments

**PHP** is the backend language we'll learn.

---

## Static vs Dynamic Websites

| Type | What it means | Example |
|------|---------------|---------|
| **Static** | Same content for everyone | A simple portfolio page |
| **Dynamic** | Content changes based on user/data | Facebook, Gmail, Amazon |

---

## Full Stack = Frontend + Backend

A developer who can do both.

### The TALL Stack (what we'll learn)

| Letter | Technology | What it does |
|--------|------------|--------------|
| **T** | Tailwind CSS | Makes things look nice (frontend) |
| **A** | Alpine.js | Adds interactivity (frontend) |
| **L** | Laravel | PHP framework (backend) |
| **L** | Livewire | Connects frontend & backend |

---

## Quick Examples

| Task | Frontend or Backend? |
|------|---------------------|
| Show a button | Frontend (HTML) |
| Button changes color on hover | Frontend (CSS) |
| Save user to database | Backend (PHP + MySQL) |
| Check if password correct | Backend |
| Display "Welcome, Kieu!" | Frontend shows it, Backend provides the name |
