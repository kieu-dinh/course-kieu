# Module 01 - Web Theory

Before writing any code, you need to understand HOW the web works. This module explains the fundamental concepts that every web developer must know.

## Learning Objectives

By the end of this module, you will understand:
- [ ] What the Internet is and how it works
- [ ] What a network, IP address, and DNS are
- [ ] What HTTP is and how requests/responses work
- [ ] What a browser does behind the scenes
- [ ] The difference between frontend and backend
- [ ] How to use browser developer tools

```
YOU (Browser)                              SERVER
    |                                         |
    |  1. "Hey, give me google.com"          |
    |  -------- HTTP REQUEST --------->      |
    |                                         |
    |  2. "Here's the HTML page"             |
    |  <------- HTTP RESPONSE ---------      |

    |  3. Browser reads HTML, shows page     |
    |                                         |
```

---

## Why This Matters

Many developers skip theory and regret it later. When something doesn't work:
- Without theory: "I don't know why it's broken"
- With theory: "Ah, the server returned a 404, the URL is wrong"

Understanding the fundamentals makes you a MUCH better problem solver.
