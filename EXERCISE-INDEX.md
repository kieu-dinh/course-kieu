## Tips for Success

- **Do exercises in order** - Each builds on previous knowledge
- **Don't skip exercises** - Every exercise teaches important concepts
- **Ask for review** - Use "check exercice X.Y" when done
- **Commit your work** - Use Git regularly from Module 03 onwards
- **If stuck for 30+ min** - Ask for help, don't struggle alone
- **Type, don't copy-paste** - Build muscle memory
- **Experiment** - Try variations, break things, learn from errors

## Need Help?

If you're stuck or have questions:

1. **Check the lesson files** - `01-xxx.md`, `02-xxx.md` in each module folder
2. **Read the exercise README** - Every exercise has detailed instructions
3. **Ask Claude** - Explain where you're stuck and what you've tried
4. **Review previous exercises** - Often similar concepts were covered before

Remember: Being stuck is part of learning. Ask questions and debug together!
