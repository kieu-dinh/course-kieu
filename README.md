# Web Development Training - Kieu

Welcome to your web development training! This course has been designed to take you from zero to a web developer capable of working on real professional projects.

## Goal

By the end of this training, you will be able to:
- Understand how the web works as a whole
- Create modern web interfaces with HTML, CSS, and Tailwind
- Program in PHP and JavaScript
- Build complete applications with Laravel and Livewire
- Use AI as a development aid (without becoming dependent on it)
- Work on real projects independently

## How to Use This Training

### Interactive Learning System

This course is designed to work **interactively with Claude** (your AI teacher):

1. **Claude guides you** - I'll tell you what to read and which exercises to do
2. **You practice** - Do the exercises with the starter files provided
3. **I review your work** - Say `check exercice X.Y` when you're done
4. **You improve** - Learn from my feedback and refine your code

📖 **Start here:** [START-HERE.md](./START-HERE.md) - Simple guide to get started

### Golden Rules

1. **Practice, practice, practice** - Each module contains exercises. Do ALL of them.
2. **Type the code yourself** - Never copy-paste. Typing helps memorize.
3. **Make mistakes** - It's normal and that's how you learn.
4. **Ask for review** - Say "check exercice X.Y" when done with an exercise.
5. **Commit regularly** - From the Git module onwards, get into the habit of saving your work.

### Module Structure

Each module contains:
- A **README.md** with the overview
- **Numbered lessons** (01-xxx.md, 02-xxx.md, etc.)
- An **exercises/** folder with practical exercises
- **Quick quizzes** within lessons to check understanding

### Progression

Do the modules in order. Each module builds on the previous ones.

## Important Note About AI

AI (Claude, ChatGPT, Cursor...) is a powerful tool, but:

1. **First, understand** - Don't use AI until you've understood the basics
2. **Then, validate** - Use AI to check your work, not to do it for you
3. **Finally, accelerate** - Once the basics are solid, AI will make you more productive

Module 09 will teach you how to use AI effectively. But until then, focus on understanding!
