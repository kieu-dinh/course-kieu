# Exercise 03 - Todo List Application

## Objective
Build a functional todo list application using vanilla JavaScript, demonstrating DOM manipulation, event handling, and state management.

## Requirements

### Core Features
- Add new todo items from form input
- Display all todo items in a list
- Mark todos as complete/incomplete
- Delete todo items
- Persist todos in localStorage
- Clear all completed items

### Advanced Features
- Edit existing todo items
- Filter todos (All, Active, Completed)
- Count active todos
- Show/hide empty state message
- Keyboard shortcuts (Enter to add)

## Starter Code
Open `starter.html` to begin the exercise.

## Learning Points
- Form handling and validation
- DOM manipulation with lists
- Event handling and delegation
- Local storage API
- State management without frameworks
- User interface updates and feedback

## Bonus Challenges
- Add due dates to todos
- Add priority levels
- Add categories/tags
- Add search functionality
- Implement undo/redo
