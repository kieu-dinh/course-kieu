# Exercise 04 - Fetch API Usage

## Objective
Master the Fetch API by making HTTP requests, handling responses, managing loading states, and dealing with errors.

## Requirements

### Part 1: Basic Fetching
- Fetch data from a public API
- Parse JSON responses
- Display fetched data on the page
- Handle loading states

### Part 2: Error Handling
- Handle network errors
- Handle HTTP error status codes
- Display user-friendly error messages
- Implement retry functionality

### Part 3: Advanced Fetching
- Send POST requests with data
- Handle request headers
- Implement request timeouts
- Cancel requests with AbortController

### Part 4: Data Management
- Cache fetched data
- Implement pagination
- Handle large datasets
- Update UI dynamically

## Starter Code
Open `starter.html` to begin the exercise.

## Public APIs to Use
- JSONPlaceholder: https://jsonplaceholder.typicode.com/
  - Posts: /posts
  - Users: /users
  - Comments: /comments
- Open Trivia Database: https://opentdb.com/api.php?amount=10&type=multiple
- Random User API: https://randomuser.me/api/?results=10

## Learning Points
- Fetch API syntax and parameters
- Promise handling with .then() and .catch()
- Async/await patterns
- Response object and methods
- Error handling strategies
- Request headers and CORS
- Loading states and UI feedback
