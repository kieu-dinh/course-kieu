# Exercise 01 - DOM Manipulation Basics

## Objective
Learn the fundamentals of DOM manipulation in JavaScript by selecting, modifying, and creating HTML elements dynamically.

## Requirements

### Part 1: Element Selection
- Select elements using `getElementById()`, `querySelector()`, and `querySelectorAll()`
- Understand the difference between selecting single and multiple elements

### Part 2: Modifying Elements
- Change text content using `textContent` and `innerHTML`
- Modify element attributes using `setAttribute()` and direct property access
- Add and remove CSS classes using `classList`

### Part 3: Creating Elements
- Create new elements using `createElement()`
- Add elements to the DOM using `appendChild()` and `insertBefore()`
- Remove elements using `removeChild()` and `remove()`

## Starter Code
Open `starter.html` to begin the exercise.

## Learning Points
- DOM tree structure and navigation
- Element selection methods and their use cases
- Content modification vs. attribute modification
- Dynamic element creation and removal
- Best practices for DOM manipulation
