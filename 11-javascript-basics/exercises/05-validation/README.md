# Exercise 05 - Form Validation with JavaScript

## Objective
Implement comprehensive form validation using JavaScript, providing real-time feedback and preventing invalid submissions.

## Requirements

### Part 1: Basic Validation
- Validate required fields
- Validate field types (email, number, text)
- Validate field lengths (min/max)
- Display validation error messages

### Part 2: Real-time Validation
- Show validation feedback as user types
- Highlight invalid fields
- Enable/disable submit button based on validity
- Clear errors when field becomes valid

### Part 3: Custom Validation
- Validate password strength
- Validate password confirmation
- Custom validation rules
- Regular expression patterns

### Part 4: Form Submission
- Prevent submission if validation fails
- Show all errors at once
- Show success message
- Reset form after successful submission

## Starter Code
Open `starter.html` to begin the exercise.

## Validation Rules to Implement
- Email: Valid email format
- Username: 3-20 characters, alphanumeric + underscore
- Password: Min 8 chars, 1 uppercase, 1 number, 1 special char
- Phone: Valid format (123-456-7890)
- Age: Between 18 and 100
- URL: Valid URL format

## Learning Points
- Form validation strategies
- Real-time validation feedback
- Error message display
- Regular expressions for patterns
- Password strength indicators
- Form state management
