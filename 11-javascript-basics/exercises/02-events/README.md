# Exercise 02 - Event Handling

## Objective
Master event handling in JavaScript by implementing click handlers, form submissions, and various event types.

## Requirements

### Part 1: Click Events
- Handle click events on buttons and links
- Use both inline event handlers and `addEventListener()`
- Prevent default behavior with `preventDefault()`

### Part 2: Form Events
- Handle form submission events
- Get form data using `FormData` or direct input access
- Validate form inputs before submission
- Reset forms programmatically

### Part 3: Other Events
- Handle mouse events (mouseover, mouseout, mousemove)
- Handle keyboard events (keyup, keydown, keypress)
- Handle input events (change, input)
- Use event delegation for dynamic content

## Starter Code
Open `starter.html` to begin the exercise.

## Learning Points
- Event types and their use cases
- Event handlers vs. event listeners
- Event object and its properties
- Event propagation (bubbling and capturing)
- Event delegation for efficient event handling
- preventDefault() and stopPropagation()
