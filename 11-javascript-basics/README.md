# Module 11 - JavaScript Basics

**Duration**: 2 weeks
**Prerequisites**: Module 10 - E-Commerce Project

---

## Learning Objectives

- Understand JavaScript fundamentals
- Manipulate the DOM (Document Object Model)
- Handle events (clicks, forms, keyboard)
- Work with arrays and objects
- Understand async concepts (setTimeout, callbacks)
- Fetch data from APIs
- Make pages interactive

---

## Why JavaScript After PHP?

You've mastered **server-side** programming (PHP). Now learn **client-side** programming (JavaScript)!

**PHP runs on the server. JavaScript runs in the browser.**

Together, they create dynamic web applications!

---

## Topics Covered

1. Variables, data types, operators
2. Functions and scope
3. Arrays and objects
4. DOM manipulation (querySelector, innerHTML, etc.)
5. Event handling (click, submit, keypress)
6. Conditions and loops
7. ES6 features (let/const, arrow functions, template literals)
8. Async JavaScript basics (setTimeout, callbacks)
9. Fetch API for AJAX requests
10. Local Storage
