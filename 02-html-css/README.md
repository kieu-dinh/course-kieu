# Module 02 - HTML, CSS & Tailwind

Now you understand how the web works. Time to build your first webpages!

## Learning Objectives

By the end of this module, you will be able to:
- [ ] Write HTML from scratch
- [ ] Style pages with CSS
- [ ] Use Tailwind CSS for rapid styling
- [ ] Build responsive layouts
- [ ] Create a complete webpage

## Duration

2 weeks

## Key Concept

```
HTML = Structure (what's on the page)
CSS = Style (how it looks)
Tailwind = CSS shortcuts (faster styling)
```
