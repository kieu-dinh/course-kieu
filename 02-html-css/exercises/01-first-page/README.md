# Exercise 01 - First HTML Page

## Objective

Create your first HTML page from scratch.

---

## Task

Create an "About Me" page with the following elements:

1. A proper HTML structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
2. A page title in the browser tab
3. Your name as a main heading (`<h1>`)
4. A paragraph introducing yourself
5. A subheading "My Hobbies" (`<h2>`)
6. An unordered list of 3 hobbies
7. A subheading "My Goals" (`<h2>`)
8. An ordered list of 3 goals (numbered)
9. A link to your favorite website
10. An image (use any image URL or placeholder like `https://via.placeholder.com/300`)

---

## Steps

1. Create a file called `about-me.html`
2. Write all the HTML yourself (no copy-paste!)
3. Open it in Chrome to see the result
4. Use DevTools to inspect your elements

---

## Expected Result

Your page should look something like:

```
My Name
━━━━━━

Hello! I'm learning web development...

My Hobbies
──────────
• Hobby 1
• Hobby 2
• Hobby 3

My Goals
────────
1. Goal 1
2. Goal 2
3. Goal 3

Visit my favorite site: [link]

[image]
```

---

## Checklist

- [ ] Page has `<!DOCTYPE html>`
- [ ] Has `<html>`, `<head>`, `<body>` tags
- [ ] Has a `<title>` tag
- [ ] Has one `<h1>` with your name
- [ ] Has at least two `<h2>` subheadings
- [ ] Has `<p>` paragraphs
- [ ] Has `<ul>` with `<li>` items
- [ ] Has `<ol>` with `<li>` items
- [ ] Has `<a>` link with `href`
- [ ] Has `<img>` with `src` and `alt`

---

## Validation

Open DevTools and check:
- No errors in the Console tab
- All elements visible in Elements tab

Ask Claude to review your code:
> "Can you review my HTML code and suggest improvements?"
