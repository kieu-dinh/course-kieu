# Project 01 - Personal Portfolio

## Objective

Create a personal portfolio website using HTML, CSS, and Tailwind.

## Duration
3-5 days

## Requirements

### Pages
1. **Home** - Hero section, brief intro
2. **About** - Your story, skills, experience
3. **Projects** - Showcase your work (can be placeholder for now)
4. **Contact** - Contact form (doesn't need to work yet)

### Features
- [ ] Responsive design (mobile-first)
- [ ] Navigation with smooth scrolling
- [ ] Consistent styling
- [ ] At least 3 projects displayed
- [ ] Contact form UI
- [ ] Footer with links

### Technical
- [ ] Pure HTML & Tailwind (no framework yet)
- [ ] Use Tailwind CDN
- [ ] Well-organized code
- [ ] Semantic HTML
- [ ] Accessible (alt tags, proper headings)

## Steps

1. Create project folder
2. Create `index.html` with Tailwind CDN
3. Build navigation
4. Build hero section
5. Build about section
6. Build projects grid
7. Build contact form
8. Build footer
9. Make responsive
10. Test on mobile
11. Push to GitHub
