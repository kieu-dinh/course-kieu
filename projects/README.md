## How to Approach Projects

1. **Read requirements completely**
2. **Plan before coding** (wireframes, database design)
3. **Build incrementally** (one feature at a time)
4. **Commit often** (meaningful commits)
5. **Test as you go**
6. **Ask for review** (Claude can review your code)

## Project Rules

- Type all code yourself (no copy-paste)
- Understand every line you write
- Use AI for help, not for doing the work
- Push to GitHub regularly
- Deploy when finished (optional but recommended)

## Getting Help

When stuck:
1. Try to solve it yourself (30 min)
2. Search the documentation
3. Ask Claude with context
4. If still stuck, ask your mentor

Good luck! 🚀
